# 🎲 Sorteador de Número

Aplicação web que sorteia um número aleatório entre 1 e 100. Desenvolvida com Python e Flask no back-end, HTML e CSS na interface.

🔗 **[Acesse o projeto ao vivo](https://projeto1-p36f.onrender.com/)**

---

## 🚀 Tecnologias utilizadas

- **Python** — linguagem principal
- **Flask** — framework web para o back-end
- **HTML5** — estrutura da interface
- **CSS3** — estilização da interface
- **Render** — deploy da aplicação

---

## ⚙️ Como rodar localmente

### Pré-requisitos
- Python 3.10+
- pip

### Passo a passo

```bash
# Clone o repositório
git clone https://github.com/strokegx/projeto1.git

# Entre na pasta do projeto
cd projeto1

# Instale as dependências
pip install -r requirements.txt

# Rode a aplicação
python app.py
```

Acesse em: `http://localhost:5000`
